STEP 1.7: Verifica Setup Completo
---------------------------------
Esegui questa query per verificare che tutto sia ok:

SELECT
    u.id,
    u.email,
    u.email_confirmed_at,
    up.username,
    up.role
FROM auth.users u
LEFT JOIN user_profiles up ON u.id = up.id
WHERE u.email = 'admin@rbslogistica.local';

================================================================================
TROUBLESHOOTING
================================================================================

❌ Login loop (torna sempre al login):
--------------------------------------
Causa: Profilo non inserito in user_profiles
Soluzione: Verifica con query SELECT (STEP 1.7) e ripeti STEP 1.6

❌ "Invalid login credentials":
-------------------------------
Causa: Utente non creato o password sbagliata
Soluzione: Verifica in Supabase > Authentication > Users

❌ "relation user_profiles does not exist":
-------------------------------------------
Causa: Schema SQL non eseguito
Soluzione: Ripeti STEP 1.2 e 1.3

❌ Errore CORS / Failed to fetch:
---------------------------------
Causa: File supabase-config.js non modificato
Soluzione: Verifica STEP 2.2 (URL e key devono essere reali, non 'YOUR_...')

❌ Pagina bianca:
-----------------
Causa: File index.html non trovato
Soluzione: Verifica STEP 2.3 (rinomina login-supabase.html a index.html)

❌ Console mostra errori:
-------------------------
1. Premi F12 nel browser
2. Vai al tab "Console"
3. Leggi l'errore
4. Cerca l'errore nelle guide (TROUBLESHOOTING_LOGIN.md)
