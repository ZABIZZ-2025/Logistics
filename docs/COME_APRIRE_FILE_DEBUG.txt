COME CAPIRE SE FUNZIONA
================================================================================

✅ FUNZIONA se:
  - L'URL nella barra del browser inizia con: http://localhost... o http://127.0.0.1...
  - Il LOG NERO in fondo alla pagina mostra messaggi in verde/cyan/rosso
  - Vedi i messaggi: "📦 Importando Supabase client..." nel log

❌ NON FUNZIONA se:
  - L'URL nella barra del browser inizia con: file:///C:/...
  - Vedi errori CORS nella console (F12)
  - Il LOG NERO è vuoto o non si carica

================================================================================
DOPO AVER APERTO CORRETTAMENTE CON HTTP
================================================================================

Una volta che il file è aperto con http:// invece di file://:

1. Il LOG NERO ti mostrerà gli altri eventuali problemi
2. Probabilmente vedrai uno di questi errori:

   a) "❌ ERRORE: supabase-config.js non configurato"
      → Soluzione: Modifica supabase-config.js con le tue credenziali Supabase

   b) "❌ ERRORE Supabase Auth: Invalid login credentials"
      → Soluzione: Crea utente in Supabase Authentication

   c) "❌ ERRORE recupero profilo: row not found"
      → Soluzione: Inserisci profilo in user_profiles con query SQL

3. Segui le istruzioni nel LOG (sono molto dettagliate)

4. Oppure leggi: DIAGNOSI_LOGIN_RAPIDA.md per le soluzioni

================================================================================
DOMANDE FREQUENTI
================================================================================

Q: Perché non posso aprire direttamente il file?
A: I browser moderni bloccano JavaScript da file:// per sicurezza.
   Supabase usa JavaScript per connettersi al cloud, quindi serve http://.

Q: Devo installare un server vero?
A: No! Questi sono server di sviluppo locali che girano solo sul tuo PC.
   Nessuno dall'esterno può accedere.

Q: Quale metodo scegliere?
A: Se hai VS Code o puoi installarlo: METODO 1 (più facile)
   Se hai Python: METODO 2 (veloce)
   Se hai Node.js: METODO 3 (funziona bene)

Q: Il server rimane sempre acceso?
A: No, si spegne quando chiudi il Prompt dei Comandi (metodi 2-3)
   o quando clicchi "Stop" in VS Code (metodo 1).
   Devi riavviarlo ogni volta che usi l'app.

Q: Posso usare l'app da smartphone dopo?
A: Sì, ma solo dopo aver risolto tutti i problemi di configurazione.
   Per l'accesso remoto serve pubblicare su Playcode o altro hosting.
   Per ora, concentrati sul far funzionare il login sul PC.
