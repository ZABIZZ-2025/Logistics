📊 TEST DI VERIFICA MANUALE:

Esegui questa query nel SQL Editor di Supabase:

SELECT
    u.id,
    u.email,
    u.email_confirmed_at,
    up.username,
    up.role
FROM auth.users u
LEFT JOIN user_profiles up ON u.id = up.id
WHERE u.email = 'admin@rbslogistica.local';

RISULTATO ATTESO:
✓ id: (UUID dell'utente)
✓ email: admin@rbslogistica.local
✓ email_confirmed_at: (data/ora, NON null)
✓ username: Amministratore
✓ role: admin

SE VEDI NULL per username/role → Vai a ERRORE 3 (inserisci profilo)
SE VEDI NULL per email_confirmed_at → Vai a ERRORE 6 (ricrea utente)
